1. Capture the microphone

First click triggers Chrome's permission prompt. After you allow it once, it stays allowed for this extension.

The bar tracks input level. Talk into the mic to confirm audio is actually flowing.

2. Speech to text

Uses the browser's built-in recognizer. Chrome streams the audio to Google's servers, so it needs a network connection.

Nothing recognised yet.

3. Text to speech

Two independent paths. The extension API needs the tts permission; the web API needs nothing at all.

4. Round trip

Listens, then reads your words back. This is the part that proves mic and speaker can coexist without fighting each other.
